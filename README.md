An interactive, high-performance 3D web toolkit featuring over 150 client-side utilities including image processing, math and financial calculators, developer encoders/formatters, unit converters, SEO tools, and everyday productivity utilities.

---

## ✨ Key Features

- **Interactive 3D Universe**: Three.js particle constellation, floating polyhedra, cyber grid floor, and mouse parallax.
- **150+ Ready Tools**: 100% client-side execution with instant calculations and zero backend delay.
- **Privacy First**: Files and text never leave the user's browser.
- **3D Tilt Cards**: Specular glare and tilt micro-interactions on hover.
- **Live Search & Filter**: Search by title, keyword, or tag (`Ctrl + K`).
- **Favorites System**: Save favorite tools persistently in `localStorage`.
- **Hostinger Compatible**: Single-folder static deployment (`public_html`).

## 🚀 Quick Start / Local Setup

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/Habibjancoder/toolwebsite.git
cd toolwebsite
# Open index.html in your browser
```
