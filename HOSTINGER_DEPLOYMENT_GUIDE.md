# 🚀 Hostinger Deployment Guide (Urdu & English)

Aapki **Nexus 3D Toolkit** website 100% Client-Side HTML, CSS, aur JavaScript par bani hai. Iska matlab hai ke iske liye kisi heavy Node.js server ya database ki zaroorat nahi hai. Yeh Hostinger par **super-fast**, bina kisi server crash ke run hogi!

---

## 🇵🇰 Hostinger Par Host Karne Ka Tareeqa (Urdu / Roman Urdu)

### Step 1: Files Ka ZIP Banayein
1. Apne computer par is project folder (`Toolkit website`) mein jayein.
2. Sabhi files aur folders select karein:
   - `index.html`
   - `css/` (folder)
   - `js/` (folder)
   - `assets/` (folder)
3. Right click karke **"Compress to ZIP file"** (ya WinRAR/7-Zip se `website.zip`) bana lein.

---

### Step 2: Hostinger cPanel / hPanel Par Login Karein
1. Apne **Hostinger** account mein login karein: [https://hpanel.hostinger.com](https://hpanel.hostinger.com)
2. **Websites** tab par click karein aur apni domain select karein.
3. **File Manager** (Files -> File Manager) ko open karein.

---

### Step 3: Files Upload Karein
1. File Manager ke andar `public_html` folder par double-click karke open karein.
2. Agar `public_html` mein pehle se koi `default.php` ya `index.php` ho to use delete ya rename kar lein.
3. Top right par **Upload** icon par click karein aur apni `website.zip` file select karein.
4. Upload mukammal hone ke baad `website.zip` par right-click karein aur **"Extract"** (Unzip) select karein.
5. Make sure karein ke `index.html` seedha `public_html/` ke andar ho (yani `public_html/index.html`).

---

### Step 4: Website Live Check Karein!
1. Ab apna browser open karein aur apni domain enter karein (maslan `https://apkidomain.com`).
2. Aapki 3D Animated 150+ Tools website foran live nazar aayegi! 🎉

---

## 🇬🇧 English Step-by-Step Instructions

1. **Compress project files**: Select `index.html`, `css`, `js`, and `assets` folders, and zip them into `site.zip`.
2. **Log into Hostinger**: Open Hostinger hPanel and go to **File Manager**.
3. **Navigate to `public_html`**: Open your website's root directory (`public_html`).
4. **Upload & Extract**: Upload `site.zip` and extract all contents directly inside `public_html`.
5. **Verify**: Ensure `index.html` is at `public_html/index.html`.
6. **Done**: Visit your domain in any browser to see the live 3D toolkit.
